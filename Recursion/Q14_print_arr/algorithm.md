## 🧠 Problem
Print all elements of an array using recursion.

## 🎯 Goal
Display array elements one by one.

## 🪜 Algorithm
1. Start with index = 0.
2. If index equals array length → stop (base case).
3. Print element at current index.
4. Call function with index + 1.
5. Continue until base case reached.

## 🧮 Time Complexity
O(n)

## 💾 Space Complexity
O(n) (recursion stack)

## 🧩 Edge Cases
- Empty array
- Single element
