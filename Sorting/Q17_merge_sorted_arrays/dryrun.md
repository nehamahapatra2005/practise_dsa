## 🔢 Input
arr1 = [1, 4, 7, 8, 10]  
arr2 = [2, 3, 9]

## ▶️ Execution

Compare 10 and 2 → swap  
arr1 = [1, 4, 7, 8, 2]  
arr2 = [10, 3, 9]

Compare 8 and 3 → swap  
arr1 = [1, 4, 7, 3, 2]  
arr2 = [10, 8, 9]

Sort both arrays  

arr1 → [1, 2, 3, 4, 7]  
arr2 → [8, 9, 10]

## ✅ Output
Merged sorted order

## 🧠 Observation
Largest elements move to second array.
