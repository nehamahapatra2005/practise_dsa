## 🧠 Problem
Sort a list of custom objects based on age.

## 🎯 Goal
Arrange objects in ascending order of age.

## 🪜 Algorithm
1. Create a class with fields (name, age).
2. Store objects in a List.
3. Use Comparator.comparingInt() to compare ages.
4. Call list.sort() to sort.
5. Print sorted list.

## 🧮 Time Complexity
O(n log n)

## 💾 Space Complexity
O(1)

## 🧩 Edge Cases
- Empty list
- Same ages
- Single object
