## 🧠 Problem
Find common elements between two lists.

## 🎯 Goal
Return a list containing elements present in both lists.

## 🪜 Algorithm
1. Create a new list from first list.
2. Use retainAll() method with second list.
3. retainAll keeps only elements that exist in both lists.
4. Return result list.

## 🧮 Time Complexity
O(n × m)

## 💾 Space Complexity
O(n)

## 🧩 Edge Cases
- One list empty
- No common elements
- Lists with duplicates
