## 🧠 Problem
Convert a List into a Set and then convert the Set back into a List.

## 🎯 Goal
Remove duplicates using Set and obtain a new List.

## 🪜 Algorithm
1. Create a List with elements.
2. Pass list into HashSet constructor to remove duplicates.
3. Create a new ArrayList from the Set.
4. Print results.

## 🧮 Time Complexity
O(n)

## 💾 Space Complexity
O(n)

## 🧩 Edge Cases
- Empty list
- All elements unique
- All elements duplicate
